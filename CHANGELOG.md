# История изменений

Версии проекта следуют формату `MAJOR.MINOR.PATCH`. Текущая версия указана в
переменной `__version__` модуля `prometheus_common.py`; оба CLI показывают её по команде `--version`. Префикс `v` ниже
обозначает выпуск. Предыдущий вариант скрипта Kubernetes ретроспективно
считается `v1.0.0`.

## v1.3.1 — 2026-10-02

- Разнесены вложенные вызовы и плотные выражения на именованные шаги в клиенте
  Prometheus, Kafka- и Kubernetes-скриптах. Значения запросов и ответов удобно
  проверять в отладчике по ходу выполнения.
- Загрузка ответа HTTP выделена из работы с кэшем в отдельный метод.
- Удалена устаревшая инструкция установки из заголовка Kubernetes-скрипта;
  актуальная инструкция находится в README.
- Формат команд и собираемых метрик не изменён.

## v1.3.0 — 2026-10-02

- `selector` поддерживается и в Kubernetes-конфигурации: условия добавляются
  к исходным `kube_*` и ingress-метрикам перед агрегацией.
- Пустой Kubernetes `selector` сохраняет прежние запросы; `prometheus.health`
  продолжает проверять API без фильтра.
- Конфликт фильтра с обязательными labels команды возвращает явную ошибку.

## v1.2.0 — 2026-10-02

- Пример Kafka-конфигурации использует устойчивый label `namespace` в
  существующем `selector` вместо `instance`, содержащего меняющийся IP пода.
- Документация уточняет, что `selector` принимает любое число точных пар
  label–value; условия применяются ко всем Kafka-запросам, включая `up`.
- Избыточные поля `label_name` и `label_value` удалены из конфигурации.
  Их значения следует перенести в `selector`: например,
  `"label_name": "namespace", "label_value": "kafka"` становится
  `"selector": {"namespace": "kafka"}`.

## v1.1.0 — 2026-10-02

### Добавлено

- Отдельный `kafka_prometheus.py` с discovery топиков, групп и пар группа–топик.
- Метрики Kafka: число брокеров, число участников группы, число партиций,
  недореплицированные партиции, сумма и максимум consumer lag.
- Общий `prometheus_common.py` для подключения к Prometheus, HTTP Basic Auth,
  проверки TLS, собственного CA и файлового кэша.
- Раздельные JSON-конфигурации для Kubernetes и Kafka, включая выбор источника
  по точным labels для Kafka.
- Проверки `prometheus.health` без кэша и `exporter.up` для Kafka.
- Единая версия `1.1.0` в переменной `__version__` и команда `--version` в обоих скриптах.
- Ключ `--debug-log PATH`: журнал URL, PromQL, HTTP-ответов, ошибок и попаданий
  в кэш с маскированием известных клиенту учётных данных.
- Подробный русский README, примеры UserParameter и конфигураций, интеграционные тесты.
- Двуязычные docstrings и комментарии к основному коду.

### Изменено

- Существующие команды Kubernetes используют общий клиент Prometheus.
- Ключ кэша учитывает URL источника и учётные данные. Старые файлы кэша
  остаются на диске, но новая версия их не использует.
- Ошибки HTTP, авторизации, TLS, JSON и неоднозначные числовые ответы больше
  не подменяются нулём: выводится ошибка в stderr и код завершения `1`.
  Успешный пустой числовой ответ Kubernetes по-прежнему возвращает `0`.
- Аргументы имени ноды в PromQL экранируются как строковые значения.
- Сообщение об отсутствующей Kafka-серии содержит запрос и ключ; для `exporter.up`
  добавлена подсказка проверить labels метрики `up`.
- Файл `VERSION` удалён; версия хранится в коде.

### Совместимость

- Для обновлённого Kubernetes-скрипта нужен `prometheus_common.py` рядом с ним.
- Прежние команды и переменные окружения Kubernetes сохранены. При установке
  примеров UserParameter следует убрать старые определения тех же ключей.
- Триггеры, в которых `0` трактовался как ошибка источника, нужно пересмотреть:
  теперь для сбоев сбора используйте контроль отсутствия данных и unsupported items.

## v1.0.0 — предыдущая версия

- Один скрипт `k8s_prometheus.py` для Kubernetes-метрик из Prometheus.
- Discovery нод и ingress service/status, проверки состояний нод и агрегаты
  кластера.
- Настройка URL, таймаута и файлового кэша через переменные окружения.
- При ошибках сбора скрипт возвращал `0`.

`v1.0.0` здесь обозначает предыдущий вариант кода; дата выпуска и Git-тег
в этом каталоге не зафиксированы.
